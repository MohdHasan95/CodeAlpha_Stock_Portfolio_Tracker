# Stock Portfolio Tracker

## CodeAlpha Python Programming Internship
Task 1: Stock Portfolio Tracker

## Project Description
This is a Python-based Stock Portfolio Tracker developed as part of the CodeAlpha Python Programming Internship.

The program allows users to select stocks, enter quantities, calculate total investment, and save portfolio details.

## Features
- Displays available stocks and their prices.
- Allows users to select multiple stocks.
- Accepts stock quantities.
- Calculates individual stock investments.
- Calculates total portfolio investment.
- Handles invalid stock names and quantities.
- Saves portfolio details in TXT or CSV format.

## Technologies Used
- Python 3
- Python IDLE
- CSV File Handling

## How to Run
1. Download Stock_Portfolio_Tracker.py.
2. Open the file using Python IDLE.
3. Press F5 to run the program.
4. Enter a stock name and quantity.
5. Type DONE to view the portfolio summary.
6. Choose TXT or CSV to save the portfolio.

## Example
AAPL: 5 shares x $180 = $900

TSLA: 2 shares x $250 = $500

Total Investment: $1400

## Note
Stock prices are predefined for demonstration purposes and are not live market prices.
